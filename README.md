# Clon de Google

Clon visual de la página principal de Google creado con HTML y CSS como ejercicio práctico de maquetación web.

## Vista previa

El proyecto reproduce una interfaz inspirada en Google con:

- Logo principal.
- Barra de búsqueda con iconos.
- Botones de búsqueda.
- Barra de navegación superior.
- Pie de página con enlaces informativos.
- Una página secundaria para los enlaces interactivos.

## Tecnologías

- HTML5
- CSS3

## Estructura del proyecto

```text
.
├── index.html       # Página principal del clon
├── copy.html        # Página secundaria de navegación
├── style.css        # Estilos compartidos por las páginas
└── img/             # Recursos gráficos del proyecto
```

## Ejecutar el proyecto

No requiere instalación ni dependencias.

1. Clona el repositorio:

```bash
git clone https://github.com/Gomezbj/clon-de-google.git
```

2. Accede a la carpeta:

```bash
cd clon-de-google
```

3. Abre `index.html` directamente en tu navegador o utiliza una extensión como Live Server en Visual Studio Code.

## Características

- Maquetación de la interfaz principal de Google.
- Diseño con HTML semántico y estilos en CSS.
- Uso de imágenes locales y recursos externos.
- Navegación demostrativa mediante enlaces internos y externos.
- Página secundaria desarrollada para representar los resultados de los enlaces.
